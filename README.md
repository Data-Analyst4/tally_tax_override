# Tally Tax Override

Custom ERPNext app that overrides Sales Invoice tax calculation to match Tally's GST calculation logic with proper rounding.

## Features
- Tally-compatible item-wise tax rounding (round_half)
- Correct CGST/SGST/IGST cumulative totals
- Proper grand total rounding adjustment
- Works after ERPNext's standard calculation

## Installation
Install on Frappe Cloud Private Bench via "Add from GitHub"

## Usage
Once installed, all Sales Invoices will automatically use Tally-compatible tax calculation.
